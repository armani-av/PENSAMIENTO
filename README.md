# Pensamiento sistémico · Definición de un problema

Sitio académico de Leonardo Armani Aguirre Vera y Herrera Mora Derek Eliam para la actividad «Investigar y definir un problema» de Pensamiento de Ingeniería (Universidad Iberoamericana). Fecha de elaboración: 23 de octubre de 2026.

## Tema

Continuidad desigual del suministro de agua para uso doméstico en Iztapalapa, Ciudad de México. El sitio presenta un episodio reciente, antecedentes cuantitativos, mapa de actores, supuestos que sostienen el sistema, delimitación, indicadores para evaluar mejoras y un enunciado formal del problema. También examina críticamente la entrega gratuita mediante pipas como respuesta vigente.

## Criterio de investigación

Los datos de 2010, 2019–2020, 2022–2023 y 2025 tienen unidades y periodos distintos. Se muestran con etiquetas propias y no se usan para inferir una serie homogénea de escasez. El corte anunciado en octubre de 2026 es una duración prevista; no se dispone aquí de una medición del tiempo real de restablecimiento ni de hogares afectados. Las experiencias cualitativas de 2010 sirven para generar hipótesis sobre el sistema, no para describir automáticamente la situación de 2026.

Los dos PDF del curso aportaron el método y los criterios del ejercicio. El contenido y las fuentes de datos están citados en la página.
